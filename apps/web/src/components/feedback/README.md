# src/components/feedback/

**用户反馈类通用组件**——展示操作结果、系统状态、异步等待等反馈信息。

## 职责

不触发任何业务操作，只负责展示信息。数据与触发时机由调用方（页面或业务组件）控制，通过 props 传入。

## 待实现组件（规划）

| 组件 | 说明 |
|---|---|
| `Toast` | 轻量级消息通知，支持 success / warning / error / info 四种类型，自动消失 |
| `Alert` | 页面内置警告框，支持关闭按钮和自定义内容 |
| `Spinner` | 加载中旋转动画，支持覆盖整个容器或内联展示 |
| `Skeleton` | 骨架屏占位，用于内容加载前的视觉占位 |
| `EmptyState` | 空数据状态展示，支持自定义图标、标题和操作按钮 |
| `ProgressBar` | 进度条，用于文件上传、任务进度等场景 |
